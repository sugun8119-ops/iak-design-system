IAK 자체 규칙 (출처에서 확인되지 않은 오류·복구)

· 오류는 error 역할 배경 + 테두리 + 아이콘 + 문장(무엇이 안 됐는지 + 다음 행동) + “다시 시도”. role=alert. 이미 한 작업(수락/완료/입력)은 사라지지 않는다고 명시.
· 입력 오류: 제출 시에만 검증, 값 보존, 필드 아래 문구, 첫 오류로 초점, 오류 개수 요약(polite).
· 완료 취소: 모든 완료는 되돌릴 수 있음(되돌리기/완료 취소). 포인트는 파생값이라 취소하면 빠지고 다시 완료해도 한 번만 반영.
· 타이머: 시간 끝 = “시간 끝” 상태로 멈추고 완료는 아이가 직접 누름(자동 완료 없음).
· 비동기 없음: loading/error는 데모 상태. 서버 성공을 주장하지 않고 “(데모)” 표기.
