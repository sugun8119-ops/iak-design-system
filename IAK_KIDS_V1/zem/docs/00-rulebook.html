반드시

· Light only. 역할 토큰만 사용 — 가까운 옛 색으로 치환 금지.
· 작은 글자 4.5:1 이상, 필수 컨트롤 경계·포커스 3:1 이상.
· Primary·Accent 위는 흰 글자, Secondary 위는 짙은 파랑(#184957).
· border-subtle은 장식용. 입력·체크박스·스위치 트랙은 border-default.
· 상태는 색 + 글자/아이콘. 선택 탭은 배경 + 표시선 + 굵기로 구분.
· 터치 영역 44px 이상(버튼·입력 48px). 긴 한글은 keep-all + anywhere로 줄바꿈.

금지

· 캐릭터·마스코트·로고 그리기, 사진·게임/서비스 화면 캡처 사용.
· 포코피아 자산 도입(색 분위기 참고만).
· ZEM 원본 자산·고유 화면/컴포넌트 조합(periwinkle 곡선 헤더 + 겹친 카드 등) 사용.
· Pretendard를 웹에 로드(Figma 전용).
