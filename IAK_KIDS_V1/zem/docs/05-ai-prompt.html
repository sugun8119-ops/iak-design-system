전체 규칙은 zem/claude-system.md. 아래는 요약입니다.

프롬프트 뼈대

ZEM_V1 스타일(라이트 전용)로 [화면]을 375px 우선 설계.
- 헤더: --zem-header periwinkle, 하단 radius 28, 흰 제목(18px bold+)
- 카드: 흰 표면, radius 20, --zem-shadow-card, 헤더 위 -40px 겹침
- action = --zem-action(#487538) pill 버튼, 포인트 = cyan/lime 타일
- window.ZEM 16개 컴포넌트만 사용, 새 로고/캐릭터 금지, 텍스트 식별 "ZEM_V1"
- 상태: default/loading/empty/error 중 의미 있는 것만

자주 틀리는 것

· Secondary(#9DDCED) 위 흰 글자 → secondary-on #184957.
· border-subtle로 입력 테두리 → border-default.
· 상태를 색만으로 표시 → 배지 글자 함께.
· 10개 패턴은 IAK KIDS 조합 예시이며 외부 서비스 화면이 아님.
