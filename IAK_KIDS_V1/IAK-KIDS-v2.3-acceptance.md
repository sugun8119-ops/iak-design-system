# IAK KIDS v2.3 확장 검수 기준

기존 62색 semantic 팔레트 유지. 기본 컴포넌트 중복 생성 없이 조합 패턴을 추가한다. 이 문서는 구현 전 합격 기준이며 통과 결과가 아니다.

| 패턴 | 기존 요소 재사용 | 상호작용 합격 기준 |
|---|---|---|
| ChildSwitcher | Select, Card, Badge | 선택 자녀와 표시 데이터 일치. 자녀 없음 안내. 키보드 선택 가능 |
| DailyTimeline | Card, Badge, Icon | 시간·제목·소요시간 명확. 현재·완료·예정은 텍스트 병기. 긴 한글 줄바꿈 |
| FocusSession | Card, Button | 시작→일시정지→재개→완료. 정지 중 시간 보존. 초기화. 매초 음성 알림 금지 |
| GoalComposer | TextField, Select, Dialog, Button | 제목 필수. 상세 설정은 선택. 오류 시 값 보존 및 초점. 정상 제출 시 한 번 추가 |
| MissionFeedback | Button, Card, Toast | 완료 및 취소 시 집계 정확. 같은 항목 재조작 시 포인트 중복 적립 없음 |

## 템플릿 적용

- 부모: 오늘 요약→대기 요청→관리, 자녀 전환 일치.
- 일정: 375px 날짜별 목록, 넓은 화면 주간 개요. 기존 일정 추가 동작 유지.
- 활동: 현재 활동과 하위 단계, 미션 완료 피드백, 빈 목록과 전체 완료 구분.

## 출처와 자체 설계 구분

- Tiimo: 시간과 하위 단계의 위계, 숫자와 시각적 진행, 주간 개요.
- Family Link: 부모 정보 위계와 자녀 전환.
- Finch: 목표 입력 단순화, 완료 후 피드백.
- IAK 자체 규칙: 오류·재시도, 완료 취소, 중복 보상 방지, 모바일 재배치, 키보드 동작.

## 검수 범위

375/834/1440px 가로 넘침, 실제 패턴 렌더링, 주요 상태 전환을 확인한다. 기존 검수 결과를 새 버전에 그대로 전용하지 않는다. 브라우저 자동 검수와 실제 기기·스크린리더 검수를 구분한다. 타이머와 미션은 메모리 기반 데모이며 서버·보상 지급 서비스와 연결되어 있지 않다.
