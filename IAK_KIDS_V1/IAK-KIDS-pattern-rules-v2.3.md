# IAK KIDS · 생활 패턴 확장 규칙

2026-09-26 · IAK 자체 설계 제안. 아래 수치는 참고 서비스에서 측정한 값이 아니라 기존 IAK 시스템에 맞춰 정한 기준이다.

## 정보와 색의 역할

현재 해야 할 행동은 화면 영역당 하나를 주 행동으로 강조한다. 나머지는 secondary 또는 text 버튼을 사용한다. 초록은 주 행동, 하늘색은 안내, 보라는 선택과 집중 표시로 사용한다. 완료는 success 역할과 ‘완료’ 텍스트를 함께 사용한다. 실패에는 error 역할을 사용하며 미완료 자체를 실패색으로 표시하지 않는다.

부모 화면은 요약·판단·관리, 아이 화면은 다음 행동·진행·격려 순서로 구성한다. 전체 카드에 강한 색을 입히기보다 작은 상태 표시와 현재 영역에 강조를 집중한다.

## 공통 구성

- 본문 16/26, 보조 문구 13/20. 정보 제목은 16/24 또는 18/26.
- 간격은 기존 4pt 배수. 카드 내부 16~24px, 제목과 내용 12~16px, 인접 제어 간격 8px 이상.
- 기존 컨트롤 12px, 카드 16px, 시트 24px 라운드를 유지한다.
- 아이가 직접 누르는 주요 행동은 44px 이상 높이를 목표로 한다.
- 상태를 색이나 아이콘 하나로만 전달하지 않는다. 긴 제목은 본문에서 줄바꿈하며 중요한 정보를 잘라 숨기지 않는다.

## ChildSwitcher

활성 자녀 이름을 요약과 요청 목록의 기준으로 사용한다. 전환 시 이전 자녀의 요청을 현재 자녀 요청처럼 잠깐 표시하지 않는다. 자녀 없음 상태에는 안내와 연결 행동 하나를 제공한다. 선택은 키보드로 가능해야 한다.

## DailyTimeline

읽기 순서는 시간→활동명→소요시간→상태→세부 단계다. 현재 항목에만 시각적 강조를 주고 완료·예정은 라벨로 구분한다. 화면을 좁혔을 때 주간 7열을 억지로 축소하지 않고 날짜 선택과 하루 목록으로 전환한다.

## FocusSession

대기→진행→일시정지→재개→완료를 명확히 구분한다. 남은 시간 숫자를 진행 표시와 함께 제공한다. 일시정지 중 시간은 줄어들지 않는다. 초기화는 초기 시간으로 복원한다. 매초 스크린리더 알림을 보내지 않고 시작·정지·완료처럼 의미 있는 변화만 알린다.

## GoalComposer

첫 화면에는 제목과 반복만 표시하고 시간·알림 등은 상세 설정에서 제공한다. 필수 제목이 비어 있으면 해당 입력에 오류를 연결하고 초점을 보낸다. 오류 뒤에도 입력을 보존한다. 한 번의 제출은 하나의 목표만 만든다. 반복 설정만 저장하는 데모를 실제 반복 일정 엔진으로 설명하지 않는다.

## MissionFeedback

진행률은 완료 항목 수/전체 항목 수로 계산한다. 포인트는 완료된 고유 항목의 합계로 계산하여 버튼 누른 횟수로 누적하지 않는다. 취소하면 완료 상태와 집계를 함께 복원한다. 보호자 승인 방식이면 대기 포인트와 확정 포인트를 분리해야 한다. 모든 항목 완료와 처음부터 목록이 없는 상태의 문구를 구분한다.
