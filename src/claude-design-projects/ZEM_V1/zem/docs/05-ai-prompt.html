프롬프트 뼈대

ZEM_V1 스타일(라이트 전용)로 [화면]을 375px 우선 설계.
- 헤더: --zem-header periwinkle, 하단 radius 28, 흰 제목(18px bold+)
- 카드: 흰 표면, radius 20, --zem-shadow-card, 헤더 위 -40px 겹침
- action = --zem-action(#4368E2) pill 버튼, 포인트 = cyan/lime 타일
- window.ZEM 16개 컴포넌트만 사용, 새 로고/캐릭터 금지, 텍스트 식별 "ZEM_V1"
- 상태: default/loading/empty/error 중 의미 있는 것만

자주 틀리는 것

· 흰 본문 텍스트를 #708CF8 위에 놓기 → action 600 또는 ink-900 사용.
· lime 위 흰 텍스트 → lime-800 텍스트.
· 원본에 있었다고 패턴을 주장 → 10개 패턴은 모두 파생 확장.
