디자인 규칙

원본 보드 관찰(periwinkle 헤더·흰 둥근 카드·cyan/lime 포인트·하단 둥근 헤더)을 ZEM_V1 규칙으로 고정합니다. 색 역할은 관찰, hex는 픽셀 샘플 추정(±4, 원본 사양값 아님), 크기는 파생값입니다. 서체는 표기된 Nanum Barun Gothic 400/700을 self-host합니다.

OBS = 역할 관찰 · hex ≈ 추정DER = 파생

역할

역할토큰값 (≈ 추정)근거
헤더/배경 브랜드--zem-header≈#708CF8역할 관찰 · hex 추정
Action(CTA·링크·포커스)--zem-action≈#4368E2역할 관찰 · hex 추정(버튼 샘플)
Progress/데이터--zem-progress#4368E2 on #E6E9FC역할 관찰 · 600은 3:1 확보용 파생
포인트 아이콘--zem-point-cyan / -lime≈#38C8E0 / ≈#DFF696역할 관찰 · hex 추정
완료 체크--zem-point-done≈#68D8A8역할 관찰 · hex 추정
표면--zem-surface#FFFFFF역할 관찰
페이지 배경--zem-bg#F4F5FEDER
본문 텍스트--zem-fg#1F2440DER

반드시

· Light only. 다크 테마 없음.
· 헤더는 periwinkle 배경 + 하단 radius 28, 흰 카드가 헤더 위로 40px 겹침.
· 카드 radius 20 · 흰 표면 · periwinkle 톤 그림자. 입력/컨트롤 radius 12, CTA는 pill.
· 흰 텍스트는 header(≈#708CF8) 위에서 18px bold 이상만(3:1). 본문 흰 텍스트는 action 600 위에서만(4.5:1+).
· 포인트 색(cyan/lime/mint)은 타일·체크·보상에만. 텍스트 색으로 쓰지 않고 짙은 700/800 톤으로 대체.
· 모든 인터랙티브 요소 44px 이상(sm 32는 밀집 표·보조 영역 한정).

금지

· 원본 사진·캐릭터(돌고래·토끼 등)·ZEM 로고·고유 카피·지도/선물 이미지 복제.
· 새 로고/마스코트 그리기. 식별은 텍스트 “ZEM_V1”로만.
· IAK/RAIS 요소(주황 action, 다크, Pretendard, gem, chrome motif) 활성 카드 사용.
· 노랑을 브랜드 주색으로 쓰기, 임의 green/pink 일반화. pink/coral은 시간표 분류·오류에만.
