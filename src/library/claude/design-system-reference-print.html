06 · GOVERNANCE

Brand & Principles

The gem mark is identity (sidebar / topbar). The chrome motif is decorative (hero / header). They never share a composition.

Five non-negotiables

  • One accent. Orange #FFA726 is the only system accent. Blue is a data role, never brand.
  • Pretendard only. Korean, English and numerals share one face.
  • Focus = border + ring. 2 px accent ring with offset, keyboard-only. Never an outer halo.
  • State = colour + text + icon. Never colour alone (WCAG 1.4.1).
  • Logo ≠ motif. Gem mark for identity; chrome motif for decoration. Never together.

Don't

  • Drop raw hexes into product code, or invent a second accent.
  • Use an outer glow / halo to indicate focus.
  • Bold body copy for emphasis — use a chip or label.
  • Use the gem mark as a hero image, or place it on a coloured glow.
  • Reach for an off-scale pixel value outside the 4 pt enum.
