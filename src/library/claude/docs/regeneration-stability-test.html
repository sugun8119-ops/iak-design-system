Next-pass priorities

  1. 1 · Bake the focus rule into the CSS layer.Add a single utility (:focus-visible → border + inset ring) so a regeneration cannot draw an outer halo even if the prompt forgets.
  2. 2 · Re-publish layout grid as CSS custom properties.Expose --page-pad, --section-gap, --card-gap at :root so layout drift becomes a one-line fix.
  3. 3 · Constrain naming via JSON enums.Move the role/type/state vocabularies from prose tables to a $enum block in tokens/*.json so AI cold-starts pull the canonical list without reading markdown.
  4. 4 · Token-only padding helper.Add a .is-md, .is-lg, .is-sm helper that resolves to spacing tokens, eliminating the off-scale-pixel temptation.
