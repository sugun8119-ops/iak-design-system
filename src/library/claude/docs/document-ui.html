Spacing

A locked 4 pt scale (4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64) drives every padding, margin and gap in the system. Off-scale literals are an audit failure.

Updated 2026.05.10k
Tokens 10 base · 11 semantic
Owner RAIS Design

If you find yourself reaching for 10px 14px, you have left the system. Use the closest token instead — the visual difference is imperceptible and the audit cost is zero.

TP 03 · Spacing Lock

From 2026.05.10j, raw pixel values outside the $enum are blocked by the QA pass. Use --space-N custom properties or the .p-N / .gap-N utilities.

Usage

Reach for the named utility first. Drop to the custom property only when you need composition (e.g. in a calc).

Card · padding 
/* ✅ Recommended — utility class */
<div class="pad-card">…</div>

/* ✅ Allowed — custom property */
.card { padding: var(--space-6); }

/* ❌ Rejected — off-scale literal */
.card { padding: 10px 14px; }

Rules

  • No literal pixel value outside the $enum may appear in component CSS.
  • Composition is allowed: calc(var(--space-6) + var(--space-2)) is fine — it always resolves to a token.
  • Never animate spacing: animate transform instead. (See Motion.)
  • Don't invent semantic names beyond those in tokens/spacing.json $semantic.
