TP 01 · LAYOUT GRID LOCK

Single source of truth for container width and grid columns.

A 12 / 8 / 4 column responsive grid keyed off viewport, with locked container max, inner padding, section gap and card gap. Hand-rolled widths are now an audit failure.

  • --container-max: 1440px · --container-pad: 24px
  • --grid-cols: 12 / 8 / 4 by media query (1024 · 640 px)
  • --section-gap: 32px · --card-gap: 24px (raised from 16)
  • .rais-container · .rais-grid · .col-span-N utilities
  • .rais-stack-section · .rais-stack-card for vertical rhythm

TP 02 · FOCUS RING SYSTEM

2 px ring · 2 px offset · semantic token · keyboard-only.

A single global rule applies to every native interactive element via :focus-visible. Hover and focus stay visually distinct; mouse focus never paints the ring.

What landed

  • --focus-ring-width: 2px · --focus-ring-offset: 2px · --focus-ring-color: var(--accent)
  • Global rule on button / a / input / select / textarea / [tabindex] / [data-focusable]
  • .is-focusable opt-in for selectable cards
  • Mouse :focus:not(:focus-visible) guard — outline none
