# Sales Portfolio 운영 흐름 검증

2026-09-16 · v0.14.0

원본은 이미 보유한 Claude Design의 IAK Sales Portfolio입니다. 새 디자인을 임의로 제작하거나 원본 파일을 수정하지 않았습니다.

1. 격리된 새 Claude 세션에서 iak-add-template 설치본을 읽고 원본 확인, 로컬 아이콘 전환, custom 템플릿 등록 CLI 실행, 30개 테스트와 빌드를 완료했습니다.
2. Codex 검수에서 숨겨진 모바일 메뉴를 별도 행으로 복원하고, 연결되지 않은 문의 CTA에 실제 전송 없는 데모 폼을 추가했습니다. 원본 섹션과 네 패키지의 동등한 강조는 유지했습니다.
3. 저장소 테스트 31개 통과. 브라우저에서 1440px 4열, 800px 2열, 375px 1열과 가로 넘침 없음, 문의 결과와 포커스 이동을 확인했습니다. 공백·이메일·입력 유지·오래된 결과 숨김은 기능 테스트로 확인했습니다.
4. 검증된 개선은 sales-portfolio의 lessons에만 포함합니다. 커스텀 preview 주소를 template.json에 제공해 AI가 실제 화면을 찾도록 했습니다.

새 세션의 URL 재생성 결과는 별도 산출물로 검수합니다. 자동화가 모든 미래 디자인의 품질을 보장하지는 않습니다. 실제 문의 발송·저장·인증은 연결하지 않았습니다.
