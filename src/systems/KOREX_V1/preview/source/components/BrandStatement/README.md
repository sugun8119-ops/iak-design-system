# BrandStatement

브랜드 이야기 블록: 12열 중 8열 텍스트(meta → heading → 본문), `primarySoft` 차분한 보조 면, padding 48, 앞뒤 섹션 간격 `space-80`.

- **색**: meta는 `primary`, 제목·본문은 `textPrimary`. `primarySoft` 위에 `textSecondary`(4.1:1)를 쓰지 않는다.
- **반응형**: 태블릿에서 전체 폭, 모바일 padding 24 + heading 28/36.
- **제공할 것**: `meta`, `title`, children(본문 한 단락). 검증되지 않은 성능·판매 실적·고객 수치를 넣지 않는다.
