# 프로젝트별 독립 디자인 시스템 규격

확정: 2026-09-25 사용자 수정 지시 반영.

IAK는 항목과 상태 케이스의 공통 기준이다. 각 프로젝트의 색상, 서체 역할, 간격, 모서리, 이미지 및 레이아웃은 해당 프로젝트가 시각적 기준이다. 서로의 스타일을 합치지 않는다.

- 16 공통 컴포넌트 family와 적용 가능한 변형/상태/콘텐츠 케이스를 대응표로 관리한다.
- 프로젝트 고유 컴포넌트와 템플릿을 유지한다. 공통 family와 조합 관계를 명시한다.
- 원본 확인 항목, 이전 합의 토큰, 새로 보완한 derived-extension을 구분한다.
- IAK에 없는 기능을 임의 추가하지 않는다. DB/Router/인증/결제 연결은 범위 밖이다.
- 원본 로고, 고유 카피, 사진, 실제 데이터는 재사용하지 않는다.
- 프로젝트별 Claude Design 제작·수정 → Figma 반영·검증 → GitHub 기록 순서로 진행한다.
- 기존 파일은 수정 전 보관하고, 외부 반영 여부를 실제 확인한 뒤 기록한다.

IAK_MASTER_V1은 범위 참조 자료이며, 프로젝트별 디자인 시스템의 완성을 대신하지 않는다.
