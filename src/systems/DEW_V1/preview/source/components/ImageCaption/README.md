# ImageCaption

The small line under an image: description plus an optional credit, 8px apart, in `meta` style (`textSecondary`).

**Consumer provides:** `caption` (or children), optional `credit` (prefixed with an em dash), `as` (`figcaption` by default — place it inside a `<figure>`; use `p` elsewhere).

Keep captions to one line on desktop; they wrap on mobile. **Don't** overlay captions on images or set them larger than 12px.
