# ArticleMeta

A wrapping row of article facts — topic, format, example reading time — 16px apart in `meta` style.

**Consumer provides:** `items[]` (short strings), optional `label` for the list (default "글 정보").

Put it directly above a story title so the tiny meta and the large serif headline sit in contrast. **Don't** add icons, pills or dividers; use example values, never real counts.
