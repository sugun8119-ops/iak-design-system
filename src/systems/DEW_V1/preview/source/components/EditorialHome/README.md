# EditorialHome

Home template: **EditorialHeader → FeatureStory → EditorialGrid (ThreeColumn, with section head) → QuoteBlock → Footer**, all inside `.dew-wrap`.

Rhythm: FeatureStory 48/72 padding, grid section 72 top and bottom, QuoteBlock 24 above / 72 below. Tablet keeps the 5:7 split with a 20 gap and drops the grid to 2 columns; mobile stacks everything into one column with 24 page padding.
