# ZEM_V1 Preview

현재는 프리뷰 계획만 포함한다. 실행 가능한 화면이나 이미지 파일은 아직 없다.

추후 `../figma-system.json`과 `../claude-system.md`를 기준으로 다음 프리뷰를 넣는다.

- **Home**: 가족 프로필, 오늘의 상태, 핵심 액션, 일정 카드.
- **Activity**: 활동 목록, 목표 진행률, 완료/빈 상태.
- **Detail**: 활동 상세, 대표 액션, 확인 모달.
- **Settings**: 설정 행, 토글, 변경 결과 피드백.

390px 모바일 화면을 기준으로 정적 이미지 또는 가벼운 HTML 프리뷰를 만들고, 320px 화면과 글자 확대 시 잘림도 확인한다. 버튼·토글·모달의 포커스/비활성 상태와 로딩·오류 상태를 함께 보여 준다.

새로 작성한 범용 문구와 가상 데이터만 사용한다. 원본 로고, SKT 브랜딩, 캐릭터, 슬라임 폰트/그래픽, 고유 카피와 화면 캡처는 포함하지 않는다.
