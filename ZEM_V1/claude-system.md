# ZEM_V1 — Friendly Family Mobile System

Friendly Mobile / Kids / Family Utility를 위한 범용 스타일 가이드. `ZEM_V1`은 자산 분류용 식별자이며 사용자 화면의 브랜드명이 아니다. 토큰의 기준은 `figma-system.json`이다. 이 JSON은 설계 명세이며 Figma 파일이나 자동 동기화 구현은 아니다.

## STYLE DNA

친근함, 명료함, 안심할 수 있는 상태 표현, 작은 성취를 중심으로 설계한다. 부드러운 모서리와 충분한 여백, 한눈에 읽히는 카드, 짧은 문장으로 가족이 일상 활동과 일정을 쉽게 이해하도록 돕는다. 특정 앱의 화면을 복제하지 않고 독립적인 정보 구조와 범용 문구를 만든다.

## Layout

- 모바일 390px 기준, 320px부터 유연하게 대응한다. 콘텐츠 최대 너비는 480px이며 넓은 화면에서는 가운데 정렬한다.
- 4열 그리드, 좌우 여백 20px, 열 간격 12px. 기본 콘텐츠는 한 열로 쌓고 짧은 동등 액션만 두 열로 배치한다.
- 간격은 4/8/12/16/20/24/32/40px. 카드 안쪽 16–20px, 카드 사이 12–16px, 섹션 사이 24–32px를 사용한다.
- 상단 앱 바 → 요약/프로필 → 핵심 액션 → 일정/활동 순으로 읽힌다. 한 화면의 대표 액션은 하나로 둔다.
- 하단 탐색은 Home, Activity, Settings의 3개 목적지로 구성한다. Detail은 항목에서 진입하고 뒤로 이동한다. 안전 영역과 하단 탐색 높이만큼 본문 여백을 확보한다.

## Typography

- 기본 서체는 운영체제 sans-serif를 사용하며 한글 폴백을 허용한다. 별도 폰트 파일은 포함하지 않는다.
- Heading 24/32px 700, Title 18/26px 600, Body 14/22px 400, Caption 12/18px 400.
- 둥근 인상은 간격과 컴포넌트 형태로 만든다. 제목은 짧게, 본문은 쉬운 말과 구체적인 동사로 쓴다.
- 주요 행동과 상태를 캡션 크기로 표현하지 않는다. 확대된 글자와 긴 이름은 줄바꿈을 허용하고 고정 높이로 자르지 않는다.

## Component Style

공통으로 흰 표면, 최소한의 구분선, 낮은 시각적 밀도를 사용한다. 카드 radius는 lg(16px), 작은 컨트롤은 sm/md(8/12px), 모달은 xl(24px)을 사용한다. 터치 영역은 최소 48×48px로 확보한다.

| Component | 구성과 규칙 |
| --- | --- |
| TopAppBar | 짧은 제목과 필요한 탐색/보조 액션만 둔다. Detail에서는 뒤로 가기를 제공한다. |
| BottomNavigation | 아이콘과 텍스트를 함께 표시하고 선택 상태를 색·형태·접근성 속성으로 전달한다. |
| ProfileCard | 이름, 중립적인 이니셜 아바타, 짧은 요약. 가족 구성원 전환은 명확한 버튼으로 제공한다. |
| StatusCard | 상태명, 핵심 수치 또는 설명, 다음 행동. 색 외에 텍스트와 아이콘으로 상태를 알린다. |
| ActionCard | 하나의 작업과 짧은 설명. 내부에 별도 버튼이 있다면 카드 전체를 중복 클릭 영역으로 만들지 않는다. |
| ProgressCard | 목표명, 현재/전체 수치, 진행 막대. 완료 상태를 문장으로도 표현한다. |
| ScheduleItem | 시간, 제목, 상태를 일정한 위치에 배치하고 긴 내용은 줄바꿈한다. |
| SettingRow | 이름, 현재 값 또는 설명, 이동/변경 컨트롤. 행마다 한 가지 설정을 담당한다. |
| Toggle | 즉시 적용 가능한 이진 설정. 연결된 라벨과 켜짐/꺼짐 상태를 제공한다. |
| Badge | 짧은 상태 라벨. 본문 흐름을 보조하며 단독으로 중요한 정보를 전달하지 않는다. |
| FriendlyModal | 명확한 제목, 짧은 설명, 대표 액션과 취소. 닫기 수단과 열린 이유를 제공한다. |

관련 컴포넌트에는 기본·누름·포커스·비활성 상태를 정의하고, 데이터 영역에는 로딩·비어 있음·오류·완료 상태를 제공한다. 오류는 원인과 재시도 방법을 가까이에 표시한다.

## Color

- Canvas `#F7F8FC`, Surface `#FFFFFF`, TextPrimary `#20232A`, TextSecondary `#737985`, Border `#E7EAF0`.
- Primary `#6C8DF5`는 친근한 파랑, Secondary `#77D5A6`는 긍정적인 보조 강조에 사용한다. Warning `#F3B84B`, Danger `#ED6A6A`는 상태 표시용이다.
- 밝은 강조색 위에는 TextPrimary를 사용한다. 흰 글자가 필요한 주요 버튼은 Action `#3858B8` + OnAction `#FFFFFF`를 사용한다.
- 작은 보조 글자는 TextMuted `#626975`, 흰 배경의 오류 글자는 DangerText `#B42332`를 사용한다. TextSecondary는 작은 본문용 기본색으로 쓰지 않는다.
- 텍스트 대비는 일반 글자 4.5:1, 큰 글자 3:1 이상을 목표로 실제 조합을 확인한다. Border는 장식용이며 컨트롤 식별을 혼자 담당하지 않는다. 포커스 링은 Action을 사용한다.
- 고유 브랜드 노랑을 주색으로 사용하거나 특정 브랜드 팔레트를 재현하지 않는다.

## Image/Graphic Direction

필요할 때만 독립적으로 제작한 단순 기하 도형, 중립적인 선형 아이콘, 이니셜 아바타를 사용한다. 그래픽보다 작업과 상태가 먼저 보이도록 한다. 사진 없이도 모든 화면이 성립해야 한다. 실제 아동 사진이나 개인 정보 대신 가상 데이터로 예시를 만든다. 의미 있는 이미지에는 대체 텍스트를 제공하고 장식 이미지는 보조기술에서 제외한다.

## Interaction

- 누름 피드백은 즉시 보여 주고 일반 전환은 150–200ms 정도의 짧고 차분한 움직임으로 표현한다. 동작 줄이기 설정을 존중한다.
- 저장/변경 결과를 가까운 위치에서 알려 준다. 진행 중에는 중복 실행을 방지하고 실패 시 복구 가능한 행동을 제공한다.
- 모든 기능은 터치 외에 키보드로도 접근 가능해야 하며 포커스가 보여야 한다. Toggle은 상태를 보조기술에 전달한다.
- 모달은 열릴 때 포커스를 내부로 옮기고 내부 탐색을 유지한다. 닫기와 Escape를 지원하며 닫힌 뒤 실행한 요소로 포커스를 돌려준다.
- 성취는 차분하게 축하한다. 과도한 보상, 경쟁 순위, 연속 사용 압박이나 강제 알림 유도는 사용하지 않는다.

## Do

- 화면마다 핵심 작업 하나와 분명한 다음 행동을 제시한다.
- 일정, 상태, 진행률을 텍스트와 수치로 설명한다.
- 짧은 범용 문구와 가상 인물/활동 데이터를 새로 작성한다.
- 토큰과 컴포넌트를 일관되게 재사용하고 좁은 화면·글자 확대·오류 상태를 확인한다.

## Don't

- ZEM 로고, SKT 브랜딩, 원본 캐릭터, 슬라임 폰트/그래픽, 고유 카피 또는 원본 화면 캡처를 포함하지 않는다.
- 원본 브랜드 이름을 제품명으로 노출하거나 공식 서비스·제휴 제품처럼 표현하지 않는다.
- 밝은 파스텔 배경에 대비가 낮은 작은 글자를 쓰지 않는다.
- 색상만으로 상태를 전달하거나 작은 아이콘에 핵심 행동을 숨기지 않는다.
- 복잡한 대시보드, 장식 위주의 일러스트, 과도한 그라디언트와 애니메이션으로 화면을 채우지 않는다.

## Default Pages

| Template | 기본 구성 |
| --- | --- |
| Home | TopAppBar, ProfileCard, StatusCard, 핵심 ActionCard, 오늘의 ScheduleItem, BottomNavigation. |
| Activity | TopAppBar, ProgressCard, 활동별 ScheduleItem과 Badge, 빈 상태/재시도, BottomNavigation. |
| Detail | 뒤로 가기가 있는 TopAppBar, 상세 StatusCard 또는 ProgressCard, 관련 일정과 한 개 대표 액션, 필요한 경우 FriendlyModal. |
| Settings | TopAppBar, ProfileCard 요약, SettingRow와 Toggle, 변경 결과 피드백, BottomNavigation. |
