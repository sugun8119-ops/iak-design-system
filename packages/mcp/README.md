# IAK Design MCP (preview)

Read-only local stdio MCP with component props/examples, tokens with media conditions, bundled icons, source-asset metadata, UI-kit layouts and coding guidelines.

Install the tarball from the IAK developer page, then register `iak-design-mcp` as a stdio command in your MCP-compatible AI tool. It reads packaged data only: no browsing, arbitrary file access, writes, credentials or account changes. Configuration is manual; visiting the website does not register this server automatically.

Tools are documented by `tools/list`. Unknown component/icon names return `isError`. Node 20+ is required. Data is a release snapshot; reinstall the newer package when source assets change.
